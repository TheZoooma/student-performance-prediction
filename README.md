# Student Performance Prediction

## Project Overview

This project develops an early warning machine learning system for identifying students who may need academic support before the end of a course.

The model uses only early-course information such as attendance, quiz results, assignment scores, and learning activity to predict whether a student is at risk.

## Business Problem

Universities often identify struggling students too late. This project aims to provide an early prediction so instructors can intervene before final performance declines.

## Machine Learning Objective

Binary Classification

Target:
- At Risk
- Not At Risk
